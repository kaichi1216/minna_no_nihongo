一類動詞 て形 音便規則速記

原形結尾て形變化範例口訣
～す→ して探す → 探してす → して
～く→ いて書く → 書いてき・ぎ 換 い
～ぐ→ いで騒ぐ → 騒いで
～う→ って買う → 買ってう・つ・る 促音って
～つ→ って待つ → 待って
～る→ って帰る → 帰って
～む→ んで飲む → 飲んでむ・ぶ・ぬ 撥音んで
～ぶ→ んで呼ぶ → 呼んで
～ぬ→ んで死ぬ → 死んで
行く ＊→ 行って（例外：不是 ×行いて）唯一例外！
